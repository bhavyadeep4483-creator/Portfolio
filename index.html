Project System Architecture

This House is Alive

Detailed technical breakdown of the systems implemented in this project:

  • isTrigger Colliders: Handled non-blocking area entry detection for pickups and trigger zones without physical rigid body collisions.
  • Scene Management: Asynchronous scene loading and transition pipelines between the exterior house and interior exploration zones.
  • Player Controller: Custom movement scripts managing velocity smoothing, input polling, and interaction states.
  • Fridge Inventory Logic: Tracks item state collection. Once exactly 4 balls are collected, it triggers a teleportation sequence back to the house.
// C# Trigger & Inventory Condition Check
void OnTriggerEnter(Collider other) {
  if(other.CompareTag("Ball")) {
    inventoryCount++;
    Destroy(other.gameObject);
    if(inventoryCount >= 4) TeleportBackToHouse();
  }
}

Dino Run

Detailed technical breakdown of the systems implemented in Dino Run:

  • Obstacle Spawning: Procedural cactus and rock spawning system with adjustable interval rates and speed multipliers.
  • Jump Physics: Custom gravity curve applied during player jumps to ensure responsive ground clearance and landing precision.
  • Game Over State Handling: Pause mechanics, collision detection with obstacles, and instant transition to retry/menu UI panels.
  • Button & UI Management: Clean event-driven UI flow for Main Menu, Gameplay HUD, and Restart triggers.
Project System Architecture

WHERE AM I

Detailed technical breakdown of the systems implemented in WHERE AM I:

  • NavMesh Enemy AI: Pathfinding agents configured to stalk and track the player across dense forest terrain.
  • Car Controller & Wheel Colliders: Advanced vehicle physics handling suspension springs, torque application, and wheel rotation.
  • Raycast Keypad Puzzle: Interactive password keypad using raycast hit detection to register code inputs.
  • Loot Tables & Dig Spots: Randomly spawning dig spots configured with weighted loot drop chances.
  • Dialogue & UI Lifecycle: Typewriter text effect for narrative delivery and auto-clearing UI message panels after timed delays.
